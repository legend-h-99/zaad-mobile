# تدفقات تجربة Zaad للجوال

## 1. تسجيل الدخول

1. يفتح المستخدم شاشة الدخول.
2. يدخل البريد وكلمة المرور، أو يختار واحداً من الحسابات التجريبية العشرين.
3. اختيار الحساب يعبئ بياناته تلقائياً.
4. عند نجاح المصادقة ينتقل المستخدم إلى شاشة اليوم.
5. عند فشل المصادقة تظهر رسالة داخل بطاقة الدخول بدون فقدان المدخلات.

## 2. اليوم وخطة الوجبات

1. يرى المستخدم نقاط زاد وملخصاً قصيراً لحالة يومه.
2. يراجع أهداف السعرات والبروتين والكربوهيدرات والدهون المحسوبة من ملفه.
3. يضغط زر تعديل الهدف لاختيار التركيز الصحي وضبط السعرات.
4. يختار يوماً من شريط الأسبوع لتحديث الخطة.
5. يضغط وجبة لعرض مكوناتها الأساسية.
6. يشارك الخطة عبر واتساب من زر المشاركة.
7. يراجع ملخص الالتزام الأسبوعي أسفل الخطة.

## 2.1 الجدول اليومي والأسبوعي والشهري

1. يضغط المستخدم عرض الجدول الكامل من شاشة اليوم.
2. يختار العرض اليومي أو الأسبوعي أو الشهري.
3. ينتقل إلى الفترة السابقة أو التالية باستخدام أزرار التنقل.
4. يعرض الجدول وجبات المستخدم الفعلية، ويكمل الأيام غير المحفوظة بخطة مقترحة.
5. يشارك الفترة المعروضة عبر واتساب على الويب أو نافذة المشاركة الأصلية على الجوال.
6. ينسخ الجدول من الموقع عند الحاجة لإرساله في تطبيق آخر.

## 2.2 اختيار الحمية وبناء الخطة

1. يفتح المستخدم نمط الحمية الغذائية من ملفه أو من صفحة خطة الوجبات في الموقع.
2. يختار من الحميات المتوازنة أو المتوسطية أو DASH أو قليلة الكربوهيدرات أو عالية البروتين أو النباتية أو النباتية الصرفة أو الكيتو أو الخالية من الغلوتين أو المناسبة لضبط السكر.
3. يحفظ التطبيق الاختيار في تفضيلات المستخدم.
4. يبني النظام خطة اليوم وفق الحمية والهدف والحالات الصحية والحساسيات.
5. يعرض جدول الجوال والموقع الوجبات الجديدة المحفوظة في Supabase.
6. عند تعذر مزود الذكاء الاصطناعي يستخدم النظام مكتبة وصفات متنوعة وآمنة بدل ترك الخطة فارغة.

## 3. إضافة قياس

1. يضغط المستخدم زر الإضافة المركزي.
2. يختار نوع السجل: وجبة، وزن، سكر، أو ضغط.
3. يظهر حقل الإدخال الخاص بالنوع المختار فقط لتقليل التشتت.
4. يضيف ملاحظة اختيارية ثم يحفظ السجل.
5. يظهر السجل ضمن قائمة آخر سبعة أيام.

## 4. صحتي والتحاليل

1. يفتح المستخدم تبويب صحتي.
2. يراجع درجة الصحة وعدد التقارير المكتملة ومؤشرات المتابعة والتنبيهات.
3. يرفع تقريراً بالكاميرا أو الصور أو ملف PDF.
4. يعرض التطبيق المؤشرات المستخرجة وحالتها.
5. يفتح المستخدم التقرير السابق لعرض صفحاته وتفاصيله.

## 5. الوصفات

1. يفتح المستخدم تبويب الوصفات.
2. يبحث بالاسم أو يختار فئة غذائية.
3. تعرض Zaad وصفات Supabase، وتعود للمكتبة المحلية عند غياب البيانات.
4. يفتح المستخدم الوصفة لرؤية المكونات والمغذيات وطريقة التحضير.
5. يمكن مشاركة الوصفة من شاشة التفاصيل.

## 6. الملف الشخصي

1. يفتح المستخدم تبويب ملفي.
2. يراجع بياناته وهدفه وحالاته وأدويته.
3. يفتح إدارة الهدف ويعتمد هدفًا جديدًا محفوظًا في Supabase.
4. يحدد أنواع التنبيهات ووقت التذكير ويحفظها على الجهاز.
5. يشارك ملخص خطته عبر نافذة المشاركة الأصلية.
6. يسجل الخروج ويعود إلى شاشة الدخول.

## 7. إنشاء الحساب وإعداد الهدف

1. ينشئ المستخدم حسابًا بالاسم والبريد وكلمة المرور.
2. يحدد الحالات الصحية، ويمكنه المتابعة دون اختيار إذا كان سليمًا.
3. يضيف العمر والجنس والطول والوزن والهدف الرئيسي.
4. يرفع تحليلًا اختياريًا أو يتخطى الخطوة.
5. يحدد المطابخ المفضلة والحساسيات.
6. يعرض التطبيق هدف السعرات والبروتين والكربوهيدرات والدهون المحسوب.
7. يعتمد المستخدم الخطة وينتقل إلى شاشة اليوم.

## 8. استعادة كلمة المرور

1. يضغط المستخدم نسيت كلمة المرور من شاشة الدخول.
2. يدخل البريد المرتبط بالحساب.
3. يرسل التطبيق رابط الاستعادة الآمن عبر Supabase.
4. يعود المستخدم إلى الدخول بعد إتمام التحديث.

## 9. العائلة والمشاركة

1. يفتح المستخدم إعدادات العائلة من ملفه.
2. يختار الأيام التي يريد تضمينها في الملخص.
3. يضيف رسالة شخصية اختيارية.
4. يشارك الخطة عبر واتساب أو نافذة المشاركة الأصلية.

## 10. الاستشارة

1. يفتح المستخدم شاشة الاستشارة من ملفه.
2. يختار المختص واليوم والوقت المناسب.
3. يؤكد الموعد ويحفظه التطبيق على الجهاز.
4. تعرض الشاشة حالة الحجز المؤكدة عند العودة إليها.

## 11. الخصوصية والبيانات

1. يفتح المستخدم شاشة الخصوصية.
2. يراجع أنواع البيانات التي تحفظها Zaad.
3. يصدر ملخص ملفه الصحي عبر نافذة المشاركة الأصلية.
4. يمكنه تسجيل الخروج من الشاشة نفسها.

## مبادئ الحركة

- انتقالات التبويبات قصيرة وهادئة.
- شاشة اليوم ومركز الإضافة يظهران بتلاشي وحركة رأسية خفيفة.
- زر الإضافة المركزي يقدم تغذية راجعة لمسية على الأجهزة.
- الاختيارات تغيّر اللون والحجم قليلًا مع الحفاظ على ثبات التخطيط.
