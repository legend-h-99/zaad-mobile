## حالة ترتيب التنفيذ المعتمد

| البند | المنجز | المتبقي |
|---|---|---|
| 1. التقارير والمؤشر | تحويل صريح يطابق عقد التخزين. عرض النتائج والتنبيهات. حذف الدرجة المشتقة من عدد التقارير. | اختبار الخدمة المنشورة ببيانات غير إنتاجية. |
| 2. البيئة وAPI وHTTPS | أولوية إعدادات الاستضافة. منع تحميل ملفات المثال تلقائيًا. إزالة فرض العنوان الفارغ. تحقق HTTPS وقت البناء والتشغيل. | اعتماد عناوين الاستضافة الفعلية والتحقق من النشر التجريبي. |
| 3. الاستعادة والموافقة والحفظ | إصلاح مسار الاستعادة للجوال، وإضافة صفحة تحديث كلمة مرور الويب. موافقة مشتركة وإعادة ضبطها عند تغيير الملف. فحص نتائج الكتابة. | اختبار روابط البريد وإعدادات Supabase الفعلية، والتحقق على جهاز أصلي. |

| 5. RLS وCI والرحلة | نجاح فحص سياسات الاستشارات في قاعدة ذاكرة محلية. فحص حالة GitHub عن بُعد. رحلة متصفح ببيانات محاكاة. | قاعدة اختبار محددة، وفحوص CI للتعديل الحالي، ورحلة كاملة في بيئة تجريبية حقيقية. |
| 6. الأداء والوصول والأجهزة | قياس ملفات البناء، وفحص عربي وعرض محدود بمتصفح، وتحسين تسميات وحالات وصول. | قياس أداء ميداني، وتدقيق وصول كامل، والتحقق على iOS وAndroid. |

API تعني واجهة الخادم. RLS تعني سياسات عزل الصفوف. CI تعني فحوص التكامل المستمر.

## التغييرات الوظيفية

- يقرأ الجوال قيم التحاليل من `extracted_values`، ويحوّل أسماء أعلام التقييم من صيغة قاعدة البيانات.
- يحتفظ بمغلف `nutrition_flags` وبتنبيهاته العاجلة حتى عند غياب التقييم.
- يعرض عدم توفر التقييم عند غياب البيانات، دون اختراع درجة صحية.
- يقبل البناء إعدادات بيئة كاملة دون ملف محلي، ويرفض إعدادات الوجهات غير الآمنة أو الناقصة.
- يتحقق معالج استعادة الجوال من المخطط والمسار ونوع التدفق وحقول الرموز قبل إنشاء الجلسة.
- يمسح حفظ كلمة المرور أو إلغاء الاستعادة حالة الاستعادة، لمنع حلقة إعادة التوجيه.
- يمر بريد استعادة الويب عبر مسار تبديل رمز المصادقة، ثم صفحة تحديث كلمة المرور.
- يسمح حارس الويب بمسارات الجلسة المطلوبة، ويستمر في حماية صفحات الحساب.
- يعيد إعداد الملف خطأً عند فشل الحفظ، بدل إعلان النجاح. تبقى الكتابة الجزئية ممكنة وتحتاج إعادة محاولة.
- يستخدم يوم القياس تاريخ الرياض في العميل والخادم، مع اختبارات حدود منتصف الليل والسنة.
- لا يخفي حذف الدواء الفاشل الدواء من الواجهة. أضيفت اختبارات للفشل المعاد ولانقطاع الطلب.
- أضيفت حالات التوسع والربط بمحتوى تفاصيل الوجبات والوصفات، وتحسين تركيز مفتاح الالتزام.

لا توفر هذه الرقعة معاملة قاعدة بيانات ذرية أو ترحيلًا جديدًا.
