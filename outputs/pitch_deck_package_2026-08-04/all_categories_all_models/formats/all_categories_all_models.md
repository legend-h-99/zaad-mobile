## كل الفئات المستهدفة

  الفئة                       الرسالة الأساسية                                                    النموذج الأنسب                               الدليل المطلوب قبل التداول الخارجي
  --------------------------- ------------------------------------------------------------------- -------------------------------------------- -----------------------------------------------------------------
  المستخدمون                  زادك يحول التحاليل والقياسات إلى وجبات يومية مفهومة وآمنة.          Consumer pitch / App story / One-pager       لقطات شاشة، تجربة مستخدم، شهادات، بيانات استخدام.
  العائلة ومقدمو الرعاية      مشاركة الخطة مع من يطبخ أو يساعد، بدون كشف كامل الملف الصحي.        Family sharing pitch / Caregiver deck        صلاحيات المشاركة، ضوابط الخصوصية، أمثلة استخدام.
  أخصائيو التغذية والعيادات   طبقة متابعة بين النصيحة الغذائية والالتزام اليومي.                  Healthcare collaborator deck                 حدود الادعاءات الطبية، سير العمل، جودة البيانات، مراجعة سريرية.
  الشركاء التجاريون           قناة موثوقة لسلوك غذائي متكرر داخل سياق صحي وثقافي واضح.            Strategic partnership pitch                  نموذج الشراكة، اقتصاديات الشريك، funnel، حالات استخدام.
  المستثمرون                  بنية تغذية علاجية عربية ذات قابلية للاستخدام المتكرر والتوسع.       Investor pitch / Fundraising deck            MAU، retention، revenue، CAC، gross margin، runway، ask.
  الفريق الداخلي              توحيد القصة، الأولويات، خارطة الإثبات، وما يجب بناؤه خلال 90 يوم.   Internal strategy deck / Operating roadmap   أولويات المنتج، المالكين، الجدول، المخاطر، المقاييس.
  مدراء محافظ الأسهم العامة   قائمة مراقبة فقط ما لم يرتبط زادك بشركة مدرجة أو أداة تداول.        Public-equity screen / Long-short gate       Ticker، سعر، سيولة، تقييم، محفزات، مخاطر، قواعد خروج.
:::

## كل نماذج العرض

:::::::::::: {.grid .three}
::: card
[01]{.tag}

### Investor Pitch

لجمع التمويل أو عرض فرصة الاستثمار.

- المشكلة والسوق
- المنتج والتفاعل
- النموذج المالي
- الطلب واستخدام التمويل
:::

::: card
[02]{.tag}

### Strategic Partner Pitch

للشركاء: عيادات، مختبرات، مزودي أغذية، جهات عافية.

- قيمة الشريك
- تدفق المستخدم
- نموذج تجاري
- خطة pilot
:::

::: card
[03]{.tag}

### Consumer App Pitch

للمستخدم النهائي أو صفحة تعريف المنتج.

- العالم الحالي
- الرغبة قبل الحل
- سهولة الاستخدام
- دعوة للتحميل أو التسجيل
:::

::: card
[04]{.tag}

### Healthcare Collaborator Deck

للأخصائيين والعيادات ومقدمي الرعاية.

- حدود طبية واضحة
- كيف يساعد الالتزام
- سير العمل
- مراجعة الخصوصية
:::

::: card
[05]{.tag}

### Board / Internal Strategy

للقرارات الداخلية وخارطة المنتج.

- قرار مطلوب
- أولويات 90 يوم
- مخاطر وموانع
- مؤشرات نجاح
:::

::: card
[06]{.tag}

### Market Map

لفهم المنافسين والفئات والسوق.

- تعريف السوق
- شرائح المستخدمين
- المنافسون
- فرص التمركز
:::

::: card
[07]{.tag}

### Company Profile

ملف مختصر عن زادك لأي جهة.

- من نحن
- ماذا نبني
- لماذا يهم
- ما المطلوب لاحقا
:::

::: card
[08]{.tag}

### Public Equity Screen

ليس توصية تداول؛ يستخدم فقط إذا توفر ticker.

- Actionability
- Variant wedge
- Catalysts
- Risk rules
:::

::: card
[09]{.tag}

### Talk Track / Demo Script

نص عرض شفهي أو demo حسب الجمهور.

- افتتاح العالم
- التوتر والرغبة
- زادك كجسر
- الخطوة التالية
:::
