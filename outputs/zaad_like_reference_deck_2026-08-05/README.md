- 16:9 presentation format
- Dark black/purple hero slides
- Large phone mockups
- Minimal slide text
- Arabic-first pitch narrative
- Market, product, business model, KPI, roadmap, ask, and source slides

Files:

- `zaad_pitch_deck_like_reference.pdf` - exported PDF deck
