# نص العرض والـ Demo / Talk Track And Demo Script

Prepared: 2026-08-04
Audience: المتحدثون والمبيعات والمؤسسون / Speakers, sales, and founders

Arabic objective: توفير نص شفهي يستخدم تسلسل الرغبة قبل الحل.
English objective: Provide a speaking script using the desire-before-solution arc.

## Persuasion Sequence
Build narrative transportation: user's world, better future, contrast, Zaadk bridge, remembered close.

## Slide Structure

### 1. افتتاح / Opening
كل يوم يسأل المستخدم: ماذا آكل اليوم مع حالتي؟
Every day the user asks: what can I eat today with my condition?

### 2. الرغبة / Desire
نريد خطة هادئة، مفهومة، وتحترم الطعام المحلي.
We want a calm plan that respects local food habits.

### 3. الجسر / Bridge
زادك يحول الملف والتحليل إلى وجبة ومتابعة.
Zaadk turns the profile and report into meals and follow-up.

### 4. النهاية / Close
الخطوة التالية: اختر الفئة، أضف الأدلة، وابن النسخة الرسمية.
Next step: choose audience, add proof, build the official deck.
