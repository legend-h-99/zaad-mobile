# خريطة السوق / Market Map

Prepared: 2026-08-04
Audience: المستثمرون والشركاء والفريق / Investors, partners, and team

Arabic objective: تعريف السوق والمنافسين وموقع زادك في التغذية الصحية العربية.
English objective: Define the market, competitors, and Zaadk's position in Arabic health nutrition.

## Persuasion Sequence
Market-map readers need structure: lead with segments, then competitive gaps, then Zaadk wedge.

## Slide Structure

### 1. تعريف السوق / Market definition
تغذية علاجية، وجبات صحية، تتبع صحي، تحاليل، عافية.
Therapeutic nutrition, healthy meals, health tracking, reports, wellness.

### 2. شرائح المستخدمين / User segments
سكري، ضغط، كوليسترول، وزن، عائلة، أخصائي.
Diabetes, pressure, cholesterol, weight, family, specialist.

### 3. المنافسون / Competitors
تحتاج أسماء ومصادر حسب السعودية والخليج.
Requires named sources for Saudi/GCC competitors.

### 4. فرصة زادك / Zaadk wedge
عربي أولا، وجبات محلية، تحاليل، عائلة، خصوصية.
Arabic-first, local meals, reports, family, privacy.
